# Expo version pin

This project is pinned to **Expo SDK 54** (see `package.json`) to match the Expo Go client used for on-device testing. Do not use SDK 56 (or later) APIs, config, or docs — they may not exist or may behave differently on SDK 54.

Read the versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code that touches Expo APIs or config.
